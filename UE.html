// SENIOR ADVICE FOR PHASE 1
  • Every time you make something work in Blueprint, ask yourself WHY it works. Read the node docs.
  • Naming conventions matter from day 1. Use prefixes: BP_, SM_, T_, M_, SK_, ABP_.
  • Don't skip the Interactive Room project — understanding timelines here will save you later in animation and gameplay.
  • Install Rider for Unreal or VS Code early, even if you're not writing C++ yet. Get comfortable with the toolchain.
